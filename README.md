# E-Commerce Theme 🛒

Bootstrap 5 ve modern web teknolojileri kullanılarak geliştirilmiş, tamamen duyarlı (responsive) bir e-ticaret web sitesi şablonudur.

## 🚀 Özellikler

* **Bootstrap 5.3.3:** En güncel Bootstrap sürümü ile modern ve hızlı arayüz.
* **Responsive Tasarım:** Mobil cihazlar, tabletler ve masaüstü bilgisayarlarla tam uyumlu.
* **Font Awesome 6:** Zengin ikon kütüphanesi desteği.
* **Sayfa Yapısı:** 
  * Anasayfa (Ürün listeleme, slider ve kategoriler)
  * Ürün Detay Sayfası
  * Sepet Sayfası (Cart)
* **Özel Tema Renkleri:** Modern mor tonlarında özel CSS entegrasyonu.

## 🛠️ Kullanılan Teknolojiler

* HTML5 / CSS3
* Bootstrap 5
* JavaScript (Bootstrap Bundle)
* Font Awesome
